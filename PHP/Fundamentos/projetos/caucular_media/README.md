# Funcionalidades  
1. **Entrada de Dados**  
   O usuário insere três notas referentes às avaliações do aluno.  

2. **Cálculo da Média**  
   - A média é calculada utilizando a fórmula da média aritmética:  
   
      $$ \text{Média} = \frac{\text{Nota1} + \text{Nota2} + \text{Nota3}}{3} $$

3. **Verificação da Situação Acadêmica**  
   - A situação do aluno é avaliada com base na média final:
     - **Aprovado**: Média maior ou igual a 7.  
     - **Recuperação**: Média entre 5 (inclusivo) e 7 (exclusivo).  
     - **Reprovado**: Média menor que 5.  

4. **Exibição dos Resultados**  
   - A média final e a situação do aluno são exibidas no terminal.
