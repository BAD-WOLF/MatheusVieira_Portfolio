Property Hooks no PHP  
---

### Implementado a partir do PHP 8.4  

Os **Property Hooks** foram introduzidos no PHP 8.4, permitindo um controle mais refinado sobre a leitura e escrita de propriedades de classes sem a necessidade de métodos `get` e `set` tradicionais 

Se quiser conferir por conta propria, fique à vontade para conferir da fonte:  
🔗 https://www.php.net/manual/en/language.oop5.property-hooks.php
