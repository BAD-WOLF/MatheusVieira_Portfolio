# 🧠 Orientação a Objetos em PHP (Conceitos de Verdade)

antes de tudo  
orientação a objetos não é sobre complicar  
é sobre **organizar**

quando o PHP começou a evoluir de verdade ele foi ganhando cara de linguagem de gente grande  
e hoje com cada versão nova ele tá cada vez mais perto de algo como um C# da vida  
então decidi não só usar os recursos modernos mas também trazer uma **filosofia mais segura e limpa** de nomeação  
tipo usar `_` pra atributo privado e `Maiuscula` pra público  
porque além de ficar padronizado deixa o código mais **previsível e respeitoso**

---

## ✨ O que é Orientação a Objetos?

orientação a objetos é uma forma de pensar o código baseado em objetos reais ou conceituais  
tipo um `Usuario`, um `Produto`, um `Aeroporto`

esses objetos têm **atributos** e **comportamentos**  
ou seja  
têm **estado** e **ação**

---

## 🧱 Conceitos Base

| Conceito         | O que é de verdade                                                                 |
|------------------|------------------------------------------------------------------------------------|
| `Classe`         | é o molde do objeto  tipo uma planta de construção                                 |
| `Objeto`         | é a instância da classe  tipo a casa construída com a planta                       |
| `Encapsulamento` | proteger os dados internos e deixar o acesso controlado por métodos                |
| `Herança`        | permite que uma classe herde propriedades e métodos de outra                       |
| `Polimorfismo`   | é quando um método pode ter comportamentos diferentes em classes diferentes        |
| `Abstração`      | focar no que importa e esconder o que é detalhe técnico                            |
