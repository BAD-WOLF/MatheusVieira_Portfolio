## Conceito

- JavaScript é a linguagem de programação da web, responsável por tornar as páginas interativas e dinâmicas
- Interpretado, leve e multi-paradigma (suporte a orientação a objetos, funcional e imperativa)
- **Executado diretamente no navegador (client-side), mas também no servidor com Node.js (server-side)**

## Funcionalidades Comuns

| Categoria              | Exemplos                              |
|------------------------|---------------------------------------|
| Manipulação DOM        | `document.querySelector`, `innerHTML`|
| Eventos                | `click`, `mouseover`, `keydown`      |
| Controle de Fluxo      | `if`, `for`, `while`, `switch`       |
| Funções e Escopo       | `function`, `arrow functions`, `let` |
| Objetos e Arrays       | `{}`, `[]`, `.map()`, `.filter()`    |
| Assíncrono             | `setTimeout`, `fetch`, `async/await` |
